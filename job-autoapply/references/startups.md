# Wellfound and Cutshort (startup platforms)

Quality over volume. Both reward tailored notes and steady (not bursty) activity. Defaults: Wellfound 8/day (hard max 15), Cutshort 10/day (hard max 20).

## Wellfound
- Pre-flight: `https://wellfound.com/jobs`; login wall → stop.
- Discover: search with role + location/remote filters; collect job id from `/jobs/<id>-...` URLs.
- Apply: **Apply** → modal with a **note** (functions as a cover letter) → **Send Application**. Applications cannot be undone.
- Note: 4–6 sentences, specific to this startup and JD: one line on why this company, two lines of concrete matching achievements with numbers from the resume, one line on availability/notice. No generic templates; never claim unverified skills.
- Mode: show the note before sending unless mode is `auto` and supervised runs ≥ 2.
- "Not enough years of experience" blocks → skip, don't try to change profile values.

## Cutshort
- Pre-flight: `https://cutshort.io/jobs`; login wall → stop.
- Discover: recommended jobs / search; read skills tags on the card — Cutshort shows match signals, use them in scoring.
- Apply: **Apply** → optional note / screening questions → submit. Same note rules as Wellfound (shorter is fine: 2–4 sentences).
- Confirm "Applied" before logging.
